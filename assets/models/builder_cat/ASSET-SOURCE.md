# Builder cat source asset

The user supplied `cat_rigged.fbx` and `cat_rigged_animation_run.blend` for the SAM-AI builder monitor and identified the model as originating from Free3D.

- `cat_rigged_source.fbx` is the preserved supplied source model.
- `builder_cat_run.glb` was exported locally from the supplied Blender file with its armature action (frames 0–36) for reliable Godot 4 import.

Before redistributing this asset publicly, the project owner should verify that the original Free3D download license permits redistribution in this repository and release archives.
