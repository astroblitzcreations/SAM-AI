# Third-party runtime notices

The Windows package includes the official Windows x64 CPU build of
[llama.cpp](https://github.com/ggml-org/llama.cpp), build `b11064`, to make
first-run setup work without a separate engine download. llama.cpp is provided
under its MIT license; its license files are included in the packaged `engine`
folder.

Users can replace the bundled CPU runtime with a compatible official llama.cpp
CUDA, Vulkan, or newer CPU release from SAM-AI's Modules tab.
